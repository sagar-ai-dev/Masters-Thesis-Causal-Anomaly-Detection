# Baselines

This directory contains the deep learning baselines for the anomaly detection thesis.

- **LSTM Autoencoder + SHAP**: Implemented and tested (`lstm_shap_baseline.py`). Evaluates anomalies based on a 95th percentile dynamic reconstruction threshold and generates post-hoc XAI metrics.

- **TCN / Transformer**: These advanced architectures are strictly reserved for future research and the upcoming journal paper.
