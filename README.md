# Multi-Domain Causal Anomaly Detection 

This repository contains the complete codebase and experiments for my Master's Thesis: **A multi-domain causal anomaly detection pipeline evaluating PCMCI, GES, and TS-CAM-UV across Robotics, Healthcare, and Industrial systems**.

## 🧠 Algorithms Evaluated

1. **PCMCI** (Peter and Clark Momentary Conditional Independence)
2. **GES** (Greedy Equivalence Search)
3. **TS-CAM-UV** (Time-Series Causal Additive Models with Unobserved Variables)

## 📊 Datasets & Domains

The pipeline is tested across three distinct domains, each with its own dataset:

1. **Robotics**: PEPPER robotics anomaly-detection dataset.
2. **Healthcare**: PTB-XL ECG database / SCP statements.
3. **Industrial**: Tennessee Eastman Process (TEP) fault detection dataset.

*(Note: Extremely large data files like `*.RData` and models are ignored via `.gitignore` to comply with GitHub's file limits. Standard datasets are included in their respective folders).*

## 🔬 Downstream Regression Variants

To evaluate the causal graphs generated by the algorithms, three downstream regression models are used for anomaly scoring:

- **Linear / OLS** (Ordinary Least Squares)
- **Polynomial** (Degree 3)
- **RBF + Ridge** (Radial Basis Function)

## 📈 Evaluation Metrics

Performance is measured using threshold-independent and threshold-dependent metrics:

- **AUC-ROC** (Continuous anomaly scores)
- **AUC-PR** (Continuous anomaly scores)
- **Precision** (Thresholded)
- **Recall** (Thresholded)
- **F1-Score** (Thresholded)
- **Accuracy** (Thresholded)

## 🚀 How To Run

Navigate to the algorithm and domain folder of your choice, install dependencies if needed, and execute the desired regression script.

### Example: Running Robotics Experiments

**For PCMCI:**
```powershell
cd PCMCI\PCMCI_robotic
python anomaly_detection.py
python anomaly_detection_polynomial.py
python anomaly_detection_rbf.py
```

**For GES:**
```powershell
cd GES\GES_robotic
python anomaly_detection_ges.py
python anomaly_detection_ges_polynomial.py
python anomaly_detection_ges_rbf.py
```

**For CAM-UV:**
```powershell
cd CAM-UV\CAM_UV_robotic
python anomaly_detection.py
python anomaly_detection_polynomial.py
python anomaly_detection_rbf.py
```

*(You can run Healthcare and Industrial experiments similarly by changing the directory to `_healthcare` or `_industrial`).*
